## 📌 О проекте

Проект представляет собой **Telegram-бота**, который:

- 🔍 ищет научные конференции по запросу пользователя  
- ➕ позволяет администраторам добавлять новые конференции  
- 📄 обрабатывает текст (OCR + парсинг)  
- 📢 генерирует посты для публикации  

В основе лежит **модульная архитектура** с разделением на:

- Telegram-интерфейс  
- бизнес-логику (services)  
- базу данных (SQLite)  

---

## 👤 Режимы работы

| Роль | Функции |
|------|---------|
| **Пользователь** | • поиск конференций по текстовому запросу<br>• просмотр результатов |
| **Администратор** | • загрузка файла с описанием конференции<br>• подтверждение OCR<br>• проверка извлечённых данных<br>• добавление хэштегов<br>• генерация и публикация поста |

## 🧠 Архитектура

### Telegram-бот

| Компонент | Назначение |
|-----------|-------------|
| handlers | обработка сообщений и callback'ов |
| keyboards | генерация кнопок |
| states | управление состояниями (FSM) |
| callbacks | структурированные callback-данные |
| constants | тексты сообщений |

### Бизнес-логика

Слой `services/`:

- изолирует логику от Telegram  
- обрабатывает данные  
- взаимодействует с БД  

### База данных

Используется **SQLite** (файловая БД без сервера).

---

### 🗄️ Модуль базы данных


#### ⚙️ Инициализация

Перед первым запуском:

```python
from database.schema import init_db

init_db()
```

Создаст файл conferences.db.


| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | PK |
| name | TEXT | Название |
| conference_date | TEXT | Дата проведения |
| location | TEXT | Место |
| submission_deadline | TEXT | Дедлайн |
| is_archived | INTEGER | 0/1 |

#### 🔧 Основные функции

##### Добавление конференции
```python
add_conference(name, conference_date, location, submission_deadline)
```
##### Поиск
```python
search_conferences(query)
```
##### Активные конференции
```python
get_active_conferences()
```
##### Архивация
```python
archive_past_conferences()
```

### 3. Инициализация БД
```python

init_db()
```
