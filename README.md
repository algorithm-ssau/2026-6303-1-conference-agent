ИИ-агент для автоматизации сбора, структурирования и поиска информации о научных конференциях

Telegram-бот для:
     • поиска научных конференций по запросу пользователя
     • добавления конференций администратором
     • генерации постов



👤 Режимы работы

     ┌───────────────┬─────────────────────────────────────────────────┐
     │ Роль          │ Функции                                         │
     ├───────────────┼─────────────────────────────────────────────────┤
     │ Пользователь  │ • поиск конференций по текстовому запросу       │
     │               │ • просмотр списка результатов                   │
     ├───────────────┼─────────────────────────────────────────────────┤
     │ Администратор │ • загрузка файла с описанием конференции        │
     │               │ • подтверждение OCR                             │
     │               │ • проверка извлечённых данных                   │
     │               │ • добавление хэштегов                           │
     │               │ • генерация и публикация поста                  │
     └───────────────┴─────────────────────────────────────────────────┘



🚀 Запуск

     1. Установка зависимостей:
          pip install aiogram

     2. Настройка
          В config.py указать:
                TOKEN = "ваш_токен"
                ADMIN_IDS = [ваш_telegram_id]

     3. Запуск
          Из корня проекта (директория conference-bot):
          python main.py
