# 2026-6303-1-conference-agent
ИИ-агент для автоматизации сбора, структурирования и поиска информации о научных конференциях
Telegram-бот с применением технологий искусственного интеллекта для парсинга PDF-файлов, поиска конференций по тематике и генерации постов в Telegram-канал.
> ⚠️ **Текущий статус:** Проект находится в стадии активной разработки. Основные модули реализованы как независимые компоненты. Часть функционала работает в демо-режиме (mock-данные, stub-посты). Интеграция модулей — следующий этап.
