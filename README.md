# 2026-6303-1-conference-agent
ИИ-агент для автоматизации сбора, структурирования и поиска информации о научных конференциях
Telegram-бот с применением технологий искусственного интеллекта для парсинга PDF-файлов, поиска конференций по тематике и генерации постов в Telegram-канал.
> ⚠️ **Текущий статус:** Проект находится в стадии активной разработки. Основные модули реализованы как независимые компоненты. Часть функционала работает в демо-режиме (mock-данные, stub-посты). Интеграция модулей — следующий этап.

### Сценарии работы (целевые, после интеграции)
**Сценарий 1 — Пополнение базы данных:**
1. Администратор загружает PDF-файл с положением конференции
2. ИИ-агент извлекает текст (OCR) и структурирует данные
3. Администратор проверяет и при необходимости правит данные вручную
4. Данные сохраняются в реляционную БД
5. ИИ-агент генерирует пост для Telegram-канала по выбранному шаблону

**Сценарий 2 — Администратор недоволен постом:**
1. Администратор оставляет комментарий к сгенерированному посту
2. ИИ-агент перегенерирует пост с учётом замечаний

**Сценарий 3 — Пользователь ищет конференции:**
1. Пользователь вводит тему своей научной работы
2. Система подбирает подходящие по тематике конференции
3. Выдаётся список конференций с пагинацией
